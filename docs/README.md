## Documentation conventions

- Keep documentation in the category that best matches its primary purpose.
- Use descriptive `kebab-case.md` filenames and absolute dates (`YYYY-MM-DD`).
- Add YAML frontmatter with tags, created/modified dates, and a lifecycle status.
- Keep nesting shallow. Create a subfolder when at least three stable, related documents justify it.
- Add a `README.md` to each documentation folder and archive superseded guidance rather than silently leaving it active.

See [Documentation Standards](./10-resources/documentation-standards.md) and the [technical templates](./10-resources/templates/README.md).
